# **App Name**: Angola Services Hub

## Core Features:

- User Authentication: Secure user authentication via email/password using Firebase Authentication.
- Service Provider Management: Allow service providers to register their business and manage services, images, pricing, and location details.
- Service Booking: Enable users to select service providers, choose time slots or dates, and book services.
- Virtual Balance: Users and service providers can purchase pre-paid credit balances for use within the app.
- Map Visualization: Display locations of hotels, services, and tourist spots via Google Maps integration.
- Information Dashboard: User and service provider dashboards to view balance, bookings, and transaction history.
- Service Discovery: Explore services via filters and searches, including hotel, restaurant, clinic, salon, and tourist categories.

## Style Guidelines:

- Primary color: Deep orange (#D45500), inspired by Angola's vibrant sunsets.
- Background color: Light cream (#F2E8D0), a desaturated, brighter shade of the primary to ensure legibility.
- Accent color: Muted green (#63A375), offering an analogous but contrasting shade for calls to action.
- Headline font: 'Playfair', serif font used for headers.
- Body font: 'PT Sans', sans-serif font to complement the readability with the 'Playfair' font
- Use custom icons to represent the various services offered.
- Employ a card-based layout to showcase service options.
- Smooth transitions when navigating between sections.
